# Proyecto de Microservicios y APIs escalables

### Veterinaria Eso
### Integrantes: Cortese Valentino

Para poder usar la aplicación es necesario tener creada la base de datos veterinaria_eso en MySQL, y levantada en el puerto 3306.

Para levantar el proyecto es necesario tener la anotación @SpringBootApplication en una de nuestras clases. En este caso se encuentra en VeterinariaEsoApplication, una vez ahi se debe correr el proyecto con la función disponible según el Ide utilizado.
